# Perguntas — Demos

Perguntas abertas, cada uma com a **default que será assumida** se ninguém responder. Perguntas
respondidas vão para o histórico no fim e as decisões ficam em `decisions.md`.

## Abertas

1. **Qual endereço público as demos vão usar?**
   Default assumido: `demos.<dominio-pessoal>` quando o domínio existir; até lá, o endereço padrão do
   Cloudflare Pages (`<projeto>.pages.dev`).
2. **A demo pode usar o nome real do comércio?**
   Default assumido: sim — apenas o nome que está na fachada e conteúdo que o próprio negócio
   publica, sempre com a faixa "proposta de demonstração" e `noindex`. Se o dono pedir para remover,
   a demo sai do ar no mesmo dia.
3. **De onde vêm as fotos?**
   Default assumido: as que o negócio já publica (Instagram, Google) ou as que o Nathan tirar na
   visita, com o dono ciente. Sem foto de banco de imagens.
4. **O link do WhatsApp usa o número real do negócio?**
   Default assumido: sim, o número público dele (é o que faz a demo funcionar no celular do dono). A
   mensagem pré-preenchida é genérica, nunca uma promessa de preço.
5. **Quando um cliente fecha, o site fica aqui?**
   Default assumido: não. O site do cliente vira repositório e domínio próprios; aqui permanece no
   máximo uma captura de tela na home, e só com autorização.
